A first answer in your terminal
Start with eight rows.
Then bring your tools.
From the repository root, configure the bundled synthetic CRM export in a new local workspace. Sync loads its contents into DuckDB and creates a context draft.
The query returns 8 accounts. No credentials, network source or model are needed after installation.
Follow the quickstart ↗Choose a connector ↗Join CRM and product exports ↗
YOUR TERMINAL · REPOSITORY ROOT
$ uv sync --frozen
$ .venv/bin/oriel --workspace .oriel-quickstart \
    source add csv --name crm \
    --path examples/tool-exports/fixtures/crm-seats.csv
$ .venv/bin/oriel --workspace .oriel-quickstart \
    source sync crm
$ .venv/bin/oriel --workspace .oriel-quickstart \
    query 'SELECT COUNT(*) AS accounts FROM crm.records'
Use a new .oriel-quickstart directory for this example.
Requires Python 3.10–3.14, uv, and a local checkout. Dependencies use the committed public lockfile.
